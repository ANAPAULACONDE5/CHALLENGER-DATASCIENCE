📊 Análise de Vendas de Lojas – Python
Este projeto realiza uma análise completa de vendas de quatro lojas virtuais, com os dados obtidos via arquivos CSV hospedados em URLs.
A aplicação utiliza Python para processar os dados e gerar estatísticas relevantes, como faturamento, vendas por categoria, avaliação média, produtos mais/menos lucrativos e custo médio de frete.
Também são geradas visualizações gráficas com matplotlib.

🚀 Funcionalidades
Leitura de dados CSV de múltiplas URLs

Cálculo do faturamento por loja e total

Análise de vendas por categoria

Cálculo da avaliação média de compras

Identificação dos produtos que mais e menos geraram receita

Cálculo do custo médio de frete por loja

Visualizações gráficas de receita total, média e distribuição

🛠️ Tecnologias utilizadas
Python 3.x

urllib.request – para download dos arquivos CSV

csv – para leitura manual dos dados (ou alternativamente pandas)

collections – para agrupamentos e somatórios

matplotlib – para criação de gráficos

pandas (opcional) – para análise de dados mais eficiente
